# 具身智能系统学习教程

欢迎来到具身智能系统学习教程。本课程从基础概念和数学工具开始，逐步进入机器人学、感知、ROS 2、仿真和机器人学习。

## 课程主线

```text
数学基础 → 机器人学 → 感知 → ROS 2 → 仿真 → RL / IL / VLA → 综合项目
```

## 学习方法

每章尽量按照以下结构组织：

1. **学习目标：** 本章结束后应该能解释或完成什么。
2. **核心概念：** 明确术语、变量、假设和系统背景。
3. **数学原理：** 给出公式、推导步骤和符号说明。
4. **算法流程：** 说明输入、处理过程、输出和边界条件。
5. **代码实践：** 提供可以运行或进一步扩展的示例。
6. **实验分析：** 观察结果、分析误差并完成练习。

## 先从哪里开始？

- 零基础：先读[开始学习](getting-started.md)和[学习路线](roadmap.md)。
- 数学基础薄弱：先学[向量与矩阵](02-mathematics/01-vectors-matrices.md)。
- 想理解机器人运动：从[坐标系](02-mathematics/02-coordinate-frames.md)和[正运动学](03-robotics/02-forward-kinematics.md)开始。
- 想快速动手：运行[二自由度机械臂项目](08-projects/01-planar-2dof-arm.md)。

## 一个具身智能闭环

```text
任务目标
  ↓
环境观测 → 状态估计 → 任务 / 运动规划 → 控制命令
  ↑                                           ↓
  └──────────── 环境变化与传感器反馈 ← 机器人执行
```

当前课程提供理论入门、公式推导、基础代码示例和实验设计。大型仿真器、真实机器人或大规模模型训练需要额外硬件与软件环境。
