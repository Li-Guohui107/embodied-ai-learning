# 综合实践项目

本模块将理论与代码结合。建议按难度从基础项目开始。

| 项目 | 核心能力 | 当前资源 |
|---|---|---|
| 01 二自由度机械臂 | FK、IK、工作空间 | Python 代码与单元测试 |
| 02 视觉颜色检测 | 图像采集、HSV 分割、质心 | OpenCV 示例 |
| 03 ROS 2 通信 | Publisher / Subscriber | Python 节点示例 |
| 04 视觉抓取系统设计 | 感知、标定、抓取规划 | 系统设计练习 |
| 05 移动机器人导航 | 定位、地图、路径规划 | 学习任务 |
| 06 VLA 操作任务 | 多模态输入、动作输出、评估 | 研究设计任务 |

## 项目报告模板

1. 任务定义与成功标准
2. 硬件 / 仿真环境及版本
3. 输入、输出和坐标系
4. 系统架构
5. 数据来源与许可证
6. 实验参数和评估指标
7. 结果与失败案例
8. 安全风险与限制
9. 复现步骤
