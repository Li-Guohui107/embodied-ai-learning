# 项目 02｜视觉颜色目标检测

## 目标

使用 OpenCV 读取摄像头图像，将图像转换到 HSV 颜色空间，分割指定颜色区域，并计算最大轮廓的中心像素坐标。

## 安装

```bash
pip install -r requirements-vision.txt
```

## 运行

```bash
python examples/vision_color_tracking/color_tracker.py --camera 0
```

按 `q` 退出。若摄像头编号不同，可尝试 `--camera 1`。

## 实验任务

1. 更换不同颜色的目标物体。
2. 调整 HSV 阈值，观察光照变化的影响。
3. 改变最小轮廓面积阈值。
4. 记录目标中心像素坐标。
5. 思考如何结合深度和相机内参恢复三维坐标。

## 限制

该程序只做颜色区域检测，不是通用物体识别模型；输出的是图像像素坐标，不是机器人基座坐标，也不会控制机器人。
