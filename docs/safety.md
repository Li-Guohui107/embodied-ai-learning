# 机器人实验安全须知

机器人系统可能产生高速运动、夹持力、碰撞和电气风险。软件演示不代表可以直接连接真实硬件运行。

## 真实硬件实验前

- 阅读机器人、夹爪、电机、电源和传感器的制造商说明。
- 明确工作空间并设置物理隔离。
- 验证急停按钮、断电方式和人工接管流程。
- 设置关节位置、速度、加速度、力矩和工作空间限制。
- 从低速、低负载和单步动作开始。
- 检查坐标系、单位、时间戳和传感器标定。
- 验证碰撞检测、故障检测和恢复策略。
- 未经验证的模型输出不得直接驱动执行器。

## 数据与模型

- 不上传 API Key、密码、个人隐私或未经授权的数据。
- 使用数据集前核对许可证、隐私要求和使用限制。
- 记录模型版本、训练数据来源和实验配置。

本教程是教育资料，不是安全认证文件，也不能替代设备说明、风险评估和专业人员指导。
