# 论文阅读指南

## 推荐阅读方法

读具身智能论文时，不要只看摘要和演示视频。建议逐项记录：

1. 研究问题是什么？
2. 使用什么机器人平台和传感器？
3. 输入、输出和动作空间是什么？
4. 数据从哪里来，是否公开，许可证是什么？
5. 模型与算法的核心创新是什么？
6. 对比了哪些基线？
7. 评估任务、成功率和测试条件是什么？
8. 是否在真实机器人上验证？
9. 失败案例和局限是什么？
10. 代码和数据是否足以复现？

## 论文阅读记录模板
