# 03｜点云处理

## 3.1 什么是点云？

点云（Point Cloud）由一组空间点构成。每个点至少包含 XYZ 坐标，也可能附带颜色、强度、法向量或语义标签。

## 3.2 数据来源

- RGB-D 相机：深度图结合相机内参反投影。
- 双目视觉：通过视差估计深度。
- LiDAR：通过测距和传感器姿态形成空间点。

## 3.3 常见处理流程

1. 读取点云，确认坐标系、单位和时间戳。
2. 去除无效点和明显离群点。
3. 体素下采样，减少计算量。
4. 根据任务裁剪工作空间。
5. 估计法向量或几何特征。
6. 聚类、分割或配准。
7. 将结果变换到规划所需坐标系。

## 3.4 典型任务

- 点云配准：估计两组点云之间的相对位姿。
- 聚类：把不同物体的空间点分组。
- 分割：区分桌面、障碍物和目标物体。
- 抓取候选生成：从物体几何形状中生成可能的抓取姿态。

## 3.5 练习

解释为什么点云下采样可以降低计算量，但过度下采样可能损失抓取所需的细节。
