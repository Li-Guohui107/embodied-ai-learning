# 04｜目标检测与视觉任务

## 4.1 目标检测

目标检测通常输出类别、置信度和边界框。它回答“图像中有什么，以及大致在哪里”。

常见输出格式：

$$
b=(x_{\min},y_{\min},x_{\max},y_{\max})
$$

## 4.2 检测、分割与跟踪

- 检测：定位物体并预测类别。
- 语义分割：为像素分配语义类别。
- 实例分割：区分同类的不同实例。
- 跟踪：在连续帧中关联同一个目标。

## 4.3 评估指标

- Precision：预测为正的样本中有多少正确。
- Recall：真实正样本中有多少被找到。
- IoU：预测区域与真实区域的交并比。
- mAP：在不同类别和阈值上汇总检测性能的常用指标。

## 4.4 从检测到抓取

目标检测只给出图像中的目标位置。机器人抓取还需要深度、相机标定、手眼标定、抓取姿态估计、碰撞检查和运动规划。
