# 术语表

| 英文 | 中文 | 解释 |
|---|---|---|
| Embodied AI | 具身智能 | 通过身体与环境交互的智能系统 |
| Agent | 智能体 | 感知环境并采取行动的实体或程序 |
| Observation | 观测 | 传感器或环境提供的数据 |
| State | 状态 | 描述系统当前情况的变量集合 |
| State Estimation | 状态估计 | 根据观测推断系统状态 |
| Actuator | 执行器 | 将控制信号转化为物理动作的装置 |
| End-effector | 末端执行器 | 机械臂末端工具或夹爪 |
| FK | 正运动学 | 从关节变量计算末端位姿 |
| IK | 逆运动学 | 从目标末端位姿求关节变量 |
| Jacobian | 雅可比矩阵 | 描述关节速度与末端速度关系 |
| Homogeneous Transform | 齐次变换 | 统一表达旋转和平移的矩阵 |
| SLAM | 同步定位与建图 | 同时估计位姿并构建地图 |
| ROS 2 | 机器人软件中间件 | 机器人软件通信与工具生态 |
| RL | 强化学习 | 通过奖励和交互学习策略 |
| IL | 模仿学习 | 从专家示范中学习行为 |
| BC | 行为克隆 | 通过监督学习拟合示范动作 |
| VLA | 视觉-语言-动作 | 将视觉、语言与机器人动作关联的模型 |
| Sim-to-Real | 仿真到现实 | 将仿真中学习或验证的策略迁移到现实 |
| Domain Randomization | 域随机化 | 随机化仿真条件以提升泛化 |
| Point Cloud | 点云 | 由三维点组成的数据集合 |
