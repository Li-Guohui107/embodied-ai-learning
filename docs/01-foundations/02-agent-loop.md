# 02｜智能体交互闭环

## 学习目标

理解 Observation、State、Action 和 Feedback 的区别，并能够解释开环与闭环控制。

## 2.1 基本循环

```text
观测 Observation
      ↓
状态估计 State Estimation
      ↓
任务 / 运动规划 Planning
      ↓
动作选择 Action Selection
      ↓
控制与执行 Control & Actuation
      ↓
环境变化与新观测 Feedback
      └──────────────────→ 回到观测
```

### 观测 Observation

观测是传感器直接提供的数据，例如图像、深度、IMU 读数和关节编码器值。观测通常包含噪声、遮挡和不完整信息。

### 状态 State

状态用于描述系统当前情况。它可能包含机器人位姿、速度、关节角、物体位置和任务进度。状态不一定能被直接测量，通常需要估计。

### 动作 Action

动作是智能体希望系统执行的控制或行为，例如目标关节位置、末端速度、移动底盘速度或高层技能指令。

### 反馈 Feedback

执行动作后，环境会发生变化。系统需要重新观测并判断动作是否达到预期。

## 2.2 开环与闭环

**开环控制：** 发送动作后不根据结果修正。若外部扰动或模型误差存在，实际结果可能偏离目标。

**闭环控制：** 根据传感器反馈计算误差，再调整动作。真实机器人通常需要闭环控制。

例如，机械臂目标角度为 $q^*$，实际测量角度为 $q$，误差为：

$$
e=q^*-q
$$

控制器根据误差生成控制量。误差越小通常意味着越接近目标，但具体效果还取决于系统动力学、传感器和控制器设计。

## 2.3 分层架构

- 高层：理解任务、分解子目标、选择技能。
- 中层：路径规划、抓取位姿、动作序列规划。
- 低层：关节位置、速度、力矩和力控制。

高层模型不应绕过低层安全机制直接驱动执行器。

## 2.4 练习

设计一个“机器人把积木从桌面 A 移到桌面 B”的闭环，标出每一步的观测、状态、动作和反馈。
