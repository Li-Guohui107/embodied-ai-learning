# 03｜具身智能系统架构与任务分层

## 3.1 为什么需要分层？

机器人任务可能同时涉及自然语言理解、场景识别、空间推理、轨迹规划和电机控制。不同模块具有不同的时间尺度和安全要求，因此常采用分层架构。

## 3.2 典型三层结构

| 层级 | 主要职责 | 示例输出 |
|---|---|---|
| 任务层 Task Layer | 理解目标、分解任务、选择技能 | `pick(object_A)` |
| 运动层 Motion Layer | 生成路径、抓取姿态和轨迹 | 末端位姿序列 |
| 控制层 Control Layer | 跟踪轨迹、处理反馈和约束 | 关节位置 / 速度 / 力矩命令 |

## 3.3 模块接口

一个可维护系统应明确模块接口：

- 输入数据类型和单位。
- 坐标系与时间戳。
- 输出格式和有效范围。
- 更新频率与延迟要求。
- 失败状态和超时处理。
- 安全约束和人工接管方式。

## 3.4 任务分解示例

“把红色方块放进盒子”可以分解为：

1. 检测方块与盒子。
2. 估计两者的三维位置和姿态。
3. 选择抓取点和抓取方向。
4. 规划接近路径。
5. 闭合夹爪并验证抓取。
6. 规划到盒子上方的路径。
7. 放置并确认物体已释放。
