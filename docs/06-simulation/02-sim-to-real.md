# 02｜Sim-to-Real：从仿真迁移到现实

## 2.1 什么是 Sim-to-Real？

Sim-to-Real 指将在仿真环境中训练或验证的策略迁移到真实机器人。仿真能提供低成本实验环境，但仿真和现实并不完全一致。

## 2.2 常见差异

- 视觉差异：光照、材质、反射、遮挡和相机噪声。
- 动力学差异：质量、惯量、摩擦、柔顺性和接触模型。
- 执行差异：电机带宽、延迟、死区和控制频率。
- 传感器差异：噪声、偏置、丢帧和时间同步。
- 环境差异：物体位置、地面条件和机械磨损。

## 2.3 常见方法

### Domain Randomization
训练时随机改变光照、纹理、物体质量、摩擦和传感器噪声，使策略适应更广泛的条件。

### System Identification
通过真实系统数据估计动力学参数，再调整仿真模型，使其更接近真实机器人。

### Real-World Fine-Tuning
在严格安全控制下采集少量真实数据，对策略或模型进行适配。

## 2.4 迁移验证清单

- [ ] 仿真和真实机器人的坐标系定义一致
- [ ] 关节方向、单位和限位已核对
- [ ] 控制频率、通信延迟和动作尺度已测量
- [ ] 传感器内外参已标定
- [ ] 速度、力矩和工作空间限制已设置
- [ ] 急停和人工接管经过验证
- [ ] 先在低风险、低速度条件下测试
- [ ] 有明确的失败检测与恢复机制

**安全原则：** 不要把仿真中成功运行的策略直接部署到真实机器人。
