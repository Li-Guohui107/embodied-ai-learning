# 01｜机器人仿真平台选型

## 1.1 为什么需要仿真？

仿真能够在真实硬件实验之前测试机器人模型、控制逻辑、传感器数据流和学习算法，降低实验成本并提升可重复性。仿真并不等于现实，物理引擎、接触模型、传感器噪声和执行器模型都会引入差异。

## 1.2 常见平台

| 平台 | 常见用途 | 学习重点 |
|---|---|---|
| MuJoCo | 刚体动力学、接触、控制研究 | 模型、动力学、控制接口 |
| Gazebo | ROS 机器人系统仿真 | ROS 集成、传感器、插件 |
| NVIDIA Isaac Sim | 高保真机器人与传感器仿真 | 场景、资产、传感器与工作流 |
| NVIDIA Isaac Lab | 基于 Isaac Sim 的机器人学习 | RL / IL 任务、训练和评估 |

## 1.3 如何选择？

- 想先理解运动学和控制：从 Python 示例或 MuJoCo 入手。
- 想学习 ROS 2 系统集成：研究 ROS 2 与 Gazebo 工作流。
- 想研究高保真传感器仿真和机器人学习：评估 Isaac Sim / Isaac Lab 的硬件要求。

## 1.4 版本和硬件

安装前核对操作系统、GPU、驱动、CUDA、Python 和仿真器版本。大型仿真平台可能有较高显存和图形性能要求。

## 1.5 练习

为一个桌面机械臂抓取项目选择仿真器，并写出选择依据：物理、传感器、ROS 集成、训练接口和硬件成本。
