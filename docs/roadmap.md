# 学习路线

这是一条建议路线，不是固定学制。可以根据已有的数学、编程和机器人基础调整节奏。

| 阶段 | 学习主题 | 关键产出 |
|---|---|---|
| 1 | 具身智能基础 | 能画出智能体交互闭环 |
| 2 | 数学与空间变换 | 能解释旋转矩阵与齐次变换 |
| 3 | 机器人运动学 | 能运行 FK / IK 示例 |
| 4 | 感知与视觉 | 能解释相机模型和深度反投影 |
| 5 | ROS 2 | 能创建节点并完成话题通信 |
| 6 | 仿真平台 | 能选定平台并运行基础场景 |
| 7 | RL / IL / VLA | 能比较不同学习范式 |
| 8 | 综合项目 | 能给出可复现实验报告 |

## 每一阶段的自测问题

### 阶段 1：基础
- 为什么识别出物体不等于完成物体操作？
- 观测、状态和动作有什么区别？

### 阶段 2：数学
- 为什么两个坐标系之间需要明确变换方向？
- 旋转矩阵为什么满足正交性？

### 阶段 3：机器人学
- 正运动学和逆运动学分别解决什么问题？
- 为什么逆运动学可能有多个解或无解？

### 阶段 4：感知
- 相机内参和外参分别描述什么？
- RGB 图像和深度图提供的信息有什么区别？

### 阶段 5：ROS 2
- Topic、Service 和 Action 有什么区别？
- TF 树为什么必须保持坐标关系一致？

### 阶段 6—8：系统与学习
- 仿真与现实之间有哪些差异？
- RL 与 IL 的训练信号有什么不同？
- VLA 的动作输出如何安全地交给控制器？
