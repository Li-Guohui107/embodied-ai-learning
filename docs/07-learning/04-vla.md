# 04｜VLA：视觉-语言-动作模型

## 4.1 什么是 VLA？

Vision-Language-Action（VLA）模型尝试将视觉观测、自然语言指令和机器人动作联系起来。它希望机器人能够结合当前场景理解“把红色积木放进盒子里”这样的任务，并产生动作表示或动作序列。

VLA 不是一个固定模型结构。不同研究在视觉编码、语言模型、动作表示、数据来源和控制频率方面存在差异。

## 4.2 典型数据流

```text
相机图像 / 机器人状态 ─┐
                       ├─> 多模态模型 ─> 动作表示 / 动作块
自然语言任务指令 ──────┘                       │
                                               ▼
                                      低层控制与安全检查
                                               │
                                               ▼
                                           机器人执行
                                               │
                                               └─> 新观测
```

## 4.3 关键问题

- 数据：需要多少示范？覆盖多少任务、物体和场景？
- 动作表示：预测关节位置、末端位姿、离散动作 token，还是动作块？
- 时序：如何处理感知、推理和执行之间的延迟？
- 泛化：面对新物体、新背景和新指令是否仍然有效？
- 安全：模型输出如何经过约束检查后才允许执行？

## 4.4 VLA 与传统机器人系统

传统系统常将感知、规划和控制拆成相对独立的模块；VLA 尝试通过大规模多模态数据学习更统一的任务到动作映射。但低层控制、碰撞检测、动作限幅和安全监督仍然重要。

## 4.5 评估维度

任务成功率、未见物体 / 场景泛化、动作平滑度、完成时间、失败类型、推理延迟，以及对扰动和遮挡的鲁棒性。
