# 01｜机器学习基础

## 1.1 数据、模型与目标

机器学习通常从数据中学习一个模型，使其在目标任务上具有较好的预测或决策能力。

常见流程：

1. 定义任务和评估指标。
2. 收集并清洗数据。
3. 划分训练集、验证集和测试集。
4. 选择模型和损失函数。
5. 训练并调参。
6. 在未见数据上评估泛化能力。

## 1.2 经验风险

给定数据集 $\{(x_i,y_i)\}_{i=1}^N$，模型参数为 $\theta$，经验风险可写为：

$$
\mathcal{L}(\theta)=\frac{1}{N}\sum_{i=1}^{N}\ell(f_\theta(x_i),y_i)
$$

其中 $f_\theta$ 是模型，$\ell$ 是单样本损失函数。

## 1.3 过拟合与泛化

模型可能在训练集表现很好，却无法处理新场景。机器人任务尤其需要关注物体、光照、视角、背景、负载和环境变化。

## 1.4 机器人学习中的数据

机器人数据可能包含图像、深度、关节状态、末端位姿、动作命令、语言指令、力传感器和任务成功标记。数据必须保持时间同步、坐标定义一致并有明确许可。

## 1.5 练习

为一个机器人抓取任务设计训练 / 验证 / 测试划分，避免同一段连续轨迹同时出现在训练集和测试集导致评估泄漏。
