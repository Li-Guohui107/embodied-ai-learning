# 03｜模仿学习（Imitation Learning）

## 3.1 基本思想

模仿学习通过专家示范学习行为。专家可以是人类遥操作员、传统规划器或已验证的控制策略。

数据通常包含：

$$
\mathcal{D}=\{(o_t,a_t)\}_{t=1}^{N}
$$

其中 $o_t$ 是观测，$a_t$ 是专家动作。

## 3.2 行为克隆（Behavior Cloning）

行为克隆将模仿学习转化为监督学习，训练策略拟合专家动作：

$$
\theta^*=\arg\min_\theta
\frac{1}{N}\sum_{i=1}^{N}
\ell(\pi_\theta(o_i),a_i)
$$

优点是实现简单、可使用离线示范；缺点是策略访问到训练数据未覆盖的状态时，误差可能逐步累积。

## 3.3 DAgger

DAgger 通过迭代收集当前策略实际访问状态上的专家标签，缓解训练分布与部署分布不一致的问题。

## 3.4 示范数据质量

应记录机器人型号和传感器配置、采集频率和时间戳、观测和动作坐标系、任务成功 / 失败标记、操作员与场景变化、数据许可和隐私限制。

## 3.5 练习

比较行为克隆和强化学习的训练信号，并解释为什么高质量示范能够降低机器人策略的探索成本。
